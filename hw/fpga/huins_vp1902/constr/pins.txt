# Ports of bow32_huins_vp1902_top -> nets of the Huins MFP-VP1902-S board.
# tools/huins_pins.py looks every net up in the board netlist (the user's
# local copy in docs/fpga/Huins_MFP-VP1902/, confidential, gitignored) and
# writes the PACKAGE_PIN lines into the build directory: no FPGA ball number
# is in the repo.
#
#   <port>   <net>        {site} = the FMC+ site number of the net names
#                         (FMC_SITE: 1, 10, 2, 20, 3, 30, 4, 40 for the silk
#                         FMC+01, FMC+10, ...; default 10)
#   [all]    lines for every build
#   [clk=x]  lines for CLK_SRC = x only
# Card ports: FMC signal names (VITA 57.4) of the FMC+_DDR2_HyperRam card
# (docs/fpga/ram_extension/, the same pins as hw/fpga/mps4/constr/*_card.xdc).
