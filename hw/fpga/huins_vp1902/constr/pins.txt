# Ports of the Huins MFP-VP1902-S tops -> nets of the board. tools/huins_pins.py
# looks every net up in the board netlist (the user's local copy in
# docs/fpga/Huins_MFP-VP1902/, confidential, gitignored) and writes the
# PACKAGE_PIN lines into the build directory: no FPGA ball number is in the repo.
#
#   <port>   <net>        {site} = the FMC+ site number of the net names
#                         (FMC_SITE: 1, 10, 2, 20, 3, 30, 4, 40 for the silk
#                         FMC+01, FMC+10, ...)
#   [all]                 lines for every build
#   [card=x]              lines for CARD = x only (the top of that card)
#   [card=x sites=a,b]    the same, and the card is only verified on these sites:
#                         tools/huins_pins.py refuses another site without --any-site
#   [clk=x]               lines for CLK_SRC = x only
# Cards (Makefile CARD):
#   ram  bow32_huins_vp1902_top, the FMC+_DDR2_HyperRam card (default FMC_SITE 10).
#        Card ports: FMC signal names (VITA 57.4) of the card (docs/fpga/ram_extension/,
#        the same pins as hw/fpga/mps4/constr/*_card.xdc).
#   cam  bow32_huins_vp1902_cam_top, the LI-IMX274MIPI-FMC camera module on the Huins
#        camera adapter (FMC_SITE 1). The adapter remaps the module's MIPI pins (clock
#        lane -> CLK0_M2C, lane 1 -> CLK1_M2C, lane 3 -> LA06) so that all five pairs and
#        the control pins land in one XPIO bank on FMC+01 (bank 705): the XPHY strobe
#        never leaves a bank. The XPHY nibble plan of the top follows from these pins at
#        build time (tcl/cam_plan.tcl, from the generated pin XDC; checked again by
#        tcl/cam_xphy.tcl). Other sites split the pairs over two or three banks: refused.

# and the FPGA.
